# Supplementary Material for LSMRA

This repository hosts the supplementary material of:

**LSMRA: LLM-Enhanced Semantic Multi-Agent Risk Analysis Framework for Interbank Credit Rating**

Yuanzhong Li, Yuxi Yan, Kun Zhu, Nana Zhang, Zhiquan Liu, and Changjun Jiang

Manuscript submitted to *IEEE Transactions on Information Forensics and Security*.

## Contents

- `supplementary_material.pdf`: compiled supplementary PDF (algorithms and the semantic embedding prompt).
- `supplementary_material.tex`: LaTeX source.

The supplementary material includes:

1. End-to-end LSMRA pipeline (Algorithm 1)
2. Multi-agent suspicious screening (Algorithm 2)
3. LLM-enhanced semantic verification (Algorithm 3)
4. Attention-guided risk propagation (Algorithm 4)
5. Statistical attack simulation (Algorithm 5)
6. Semantic embedding instruction (Prompt 1) and the discrete state-label mapping

Please cite the main paper if you use this material.
